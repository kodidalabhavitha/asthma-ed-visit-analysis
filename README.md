# Asthma Emergency Department Visit Rates Analysis

**Course:** AIT 580 – Analytics Big Data to Information  
**University:** George Mason University

## Project Overview

An academic data analytics project examining asthma-related emergency department visit rates using SQL, Python, and R.

The repository contains the project dataset, analysis code, and final report.

## Technologies Used

- **SQL:** Data querying and analysis
- **Python:** Data analysis and reporting
- **R:** Statistical analysis
- **HTML:** Exported Python analysis output

## Repository Structure

- `data/` – Project dataset
- `sql/` – SQL queries
- `r/` – R analysis code
- `python/` – Python analysis exported as HTML
- `report/` – Final academic project report

## How to Review

Start with the final project report for context, then explore the SQL, R, and Python analysis files.
